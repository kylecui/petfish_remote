# PetFish Remote

PetFish Remote connects your local OpenCode sessions to Telegram for remote agent control.

## Architecture

[ Telegram Bot ] <--> [ Bot Server ] <--> [ Connector ] <--> [ Local OpenCode Session ]

## Features

* Remote Agent Control: Send instructions to your local AI agent from anywhere.
* Daemon Mode: Runs silently in the background.
* Auto-Update: Connectors synchronize with the server version automatically.
* Self-Hostable: Deploy your own server for total privacy.
